# Zolive

Boutique en ligne d'huiles d'olive et d'épicerie fine (catalogue fictif de démonstration).

Ce dépôt contient le site et, surtout, la démarche qui l'encadre : audit de cadrage,
décisions d'architecture justifiées, plan de projet agile et guides de méthode.

> État du projet : **Sprint 0 — cadrage**. Aucun code applicatif n'est encore écrit ;
> le développement démarre une fois le cadrage validé.
